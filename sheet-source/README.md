# スプシ移植の元データ

HIF計算機スプレッドシート（ユーザー提供）を xlsx でダウンロードし、
シートごとに `json/<シート名>.json`（セル → `{v: 値, f: 数式}`）へ展開したもの。

- 取得元: https://docs.google.com/spreadsheets/d/1fnKFcuv3yz35C4wNuCA0Dhxz2KgrPIiEC8o36qKQ0zs/
- 再取得・再展開: `curl -L -o hif.xlsx "<上記URL>/export?format=xlsx"` → `node extract.js`（要unzip済みディレクトリ）
- 閲覧: `node view.js <シート名> <行from> <行to> [列from] [列to] [--f]`

## 移植メモ（解析済みの構造）

- **点数計算の本体**: `メイン1DB` F2 のLET式（メイン2DB/サブDBも同形）。
  カードの点数 = Σ(アビリティ1,2,4,5,6) 効果量 × 発動回数。**アビリティ3は計算対象外**。
  - 効果量 = アビリティ性能!C:H を `レアリティ+アビリティ名` で引き、ティアは 強化段階（凸→Ⅰ〜Ⅴ）
  - 発動回数 = アビリティ発動回数!A:B を「回数参照キー」で引く。キーは アビリティ性能!I/J/K 列
    （メイン1時/メイン2時/サブ時で別。例: レッスン → メイン1レッスン）
  - パラメータボーナスは特殊: パラボ参照用!D:D を `ロール+%値` で引いて固定値化（列I=最終前）
- **発動回数シートの自動行**: メイン1レッスン等は レッスン・試験・授業 のロール割当から
  COUNTIF("TRUETRUE") で自動集計。手動行は選択中セット（列D:E）から。
  回数変更なしアビリティ（初期値=1等）は アビリティ性能!M→O。
- **アイテム補正**: Pアイテム!A:H を カード名で引いて ROUNDDOWN。
- **検算**: メイン1DB/メイン2DB/サブDB の計算済み値（0凸〜4凸×全カード）がJSONに
  入っているので、移植ロジックの出力と突き合わせるテストを書くこと。
- IMPORTRANGE（アプデ管理）は外部スプシ参照のためスキップ。
