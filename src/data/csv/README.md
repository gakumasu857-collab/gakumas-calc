# CSVデータの置き場所

Googleスプレッドシートから **ファイル → ダウンロード → カンマ区切り(.csv)** で
ダウンロードしたCSVをこのフォルダに置く。

| ファイル名 | 内容 | 変換コマンド |
| --- | --- | --- |
| `サポカDB.csv` | サポートカードのDB | `npm run gen:cards` |

変換すると `src/data/generated/*.json` が更新され、アプリが読み込む。

## 注意
- 文字コードは **UTF-8**（Googleスプレッドシートのダウンロードなら自動でUTF-8）。
  Excelで保存し直すとShift_JISになって文字化けするので注意。
- 列の追加・並び替えは自由（ヘッダー名で読むため壊れない）。
  主要列（サポカ名称・レアリティ・タイプ・アビリティ1〜6など）の**列名を変えた**ときだけ
  `src/data/supportCardsDb.ts` の `COL` を合わせて直す。
- 新しいアビリティ名を書いたときは `src/data/constants.ts` の `ABILITY_NAMES` に
  キーを追加する（忘れても開発中にコンソールへ警告が出て、データは失われない）。
