# 自動探索のしくみ（やさしい説明）

計算ページの青いボタン「評価値が最も高くなる編成と踏み方を求める」を押したとき、
中で何が起きているかを、プログラムを読まない人・ゲームに詳しくない人にも分かるように説明します。

- もっと細かい話（定数の名前・ファイルの場所）は `docs/ARCHITECTURE.md` の 3-5・3-6 にあります。
- この文書の数字（◯秒・◯通り）は 2026-09 時点のものです。調整で変わることがありますが、流れは同じです。

---

## 1. 探索は「何を」決めているのか

1回の育成で決めることは、大きく分けて2つです。

| 決めること | 中身 |
|---|---|
| **サポカ編成** | 6枚のサポートカード（うち1枚はレンタルでもよい） |
| **踏み方** | レッスンでどのタイプ（Vo／Da／Vi）を踏むか・SPレッスンか、授業（営業）でどのタイプを上げるか、H.I.Fなら選抜試験の点数をどのタイプに配るか |

探索は、この2つの組み合わせの中から **評価値がいちばん高くなりそうなもの** を探して、画面に反映します。

> たとえるなら「遠足のおやつを予算内でいちばん満足できるように選ぶ」のと同じ種類の問題です。
> ただし、おやつ同士に相性があり（一緒に買うと得をする）、入れ物にも上限がある、というところが難しい点です。

---

## 2. なぜ「全部ためす」ができないのか

いちばん確実なのは、すべての組み合わせを計算して、いちばん高いものを選ぶことです。
でも、組み合わせの数が多すぎます。

- 所持サポカが 100 枚あるとき、6枚の選び方だけで **約12億通り**
- 踏み方も、レッスン8回 × 3タイプ × サブ × SP、授業6回 × 3タイプ、選抜の配分 …で **何百万通り以上**
- この2つの掛け算なので、全部を計算すると何年もかかります

そこで探索は、次の2つの考え方を組み合わせて、**約7秒** で「かなり良い答え」を出します。

1. **見込みのないものを早めに捨てる**（候補を絞る）
2. **良さそうな答えを、少しずつ直してもっと良くする**（山登り）

> そのため、探索の答えは「絶対にいちばん」とは限りません（近似です）。
> そのかわり **乱数（サイコロ）を使っていない** ので、同じ状態から押せば基本的に同じ答えになります
> （探索の一部は残り時間を見ながら進めるので、端末の速さによってわずかに変わることはあります）。

## 3. 「良い」をどうやって数字にしているか

探索は、候補ごとに点数を付けて比べます。点数の付け方は、計算ページに出る評価値と同じ考え方です。

### 3-1. サポカ1枚の点数

```
サポカ1枚の点数 ＝（アビリティの効果の大きさ × そのアビリティが発動する回数）の合計
```

- 「発動する回数」は **プロデュース**（発動回数のセット）で決まります。
  例: 「お出かけ時にステ+10」のカードは、プロデュースでお出かけが5回なら +50。
- レッスンに関するアビリティは、**そのタイプを何回踏むか** で回数が決まります。
- 探索は、レッスンと授業（営業）は**全部踏む**前提で考えます（何も踏まずに「休む」という選び方は試しません）。
  だから **踏み方を変えると、サポカの点数も変わります**。ここが、編成と踏み方を一緒に考えないといけない理由です。

### 3-2. 6枚そろったときに起きること

- **相互作用**: あるカードの前イベ・後イベが「スキル獲得」などの回数を増やすと、その回数で動く **ほかのカードの点数も上がります**。1枚ずつの点数を足すだけでは正しくありません。
- **パラメータボーナス（パラボ）**: %で上がる分は、メモリー・Pアイドル・サポカの%を **全部足してから** 計算します。
- **上限**: 各タイプのステータスには上限があります（H.I.F 3200／N.I.A 2600／初 3000 など）。**上限を超えた分は評価値に入りません**。

> 上限があるので、「点数の高いカードを上から6枚」では最善になりません。
> たとえば Vocal がもう上限なのに Vocal のカードを足しても、あふれるだけで意味がないからです。
> 探索は「あふれさせずに、3タイプの合計をいちばん高くする」組み合わせを探しています。

### 3-3. 比べるときの点数

```
比べる点数 ＝ 3タイプの育成後ステータスの合計（上限まで）
            ＋ スター性をステータスに換算した分（H.I.F）
            ＋ スキル獲得によるファン投票数を換算した分（N.I.A）
            − 「条件設定」を守れていないときの大きな減点
```

## 4. 探索の流れ（ボタンを押してからの約7秒）

```
① 候補を絞る ─→ ② レッスンの配り方を全部ならべる ─→ ③ 有望な配り方で6枚を組む
      ─→ ④ 踏み方を詰め直す ─→ ⑤ 仕上げ（合わせ技）─→ ⑥ 最後の整え ─→ ⑦ 今より良ければ反映
```

### ① 候補を絞る（ショートリスト）

代表的な踏み方を4つ（全部Vo／全部Da／全部Vi／3タイプ均等）用意して、所持サポカ全部に点数を付けます。
そのうえで、タイプごとに次のカードだけを残します。

- 点数の高い順に 12 枚
- 前イベ・後イベでほかのカードの回数を増やしてくれるカード（配り屋）6 枚
- SPレッスン率を上げるカード 3 枚
- レンタルの候補、アシスト（トレーナーなど）、**固定** に指定したカード

> ここで外れるのは「どの踏み方でも点数が低いカード」だけです。BAN に指定したカードや、Pアイドルのプランで使えないカードは最初から候補に入りません。

### ② レッスンの配り方を全部ならべる

「レッスン8回のうち、Voを何回・Daを何回・Viを何回踏むか」の分け方は、H.I.Fなら **45通り** しかありません（N.I.A 36通り・初 21通り）。
これは少ないので **全部ためします**。それぞれについて小さな探索で6枚を組み、ざっくりの点数を付けて順位を決めます。

### ③ 有望な配り方で、6枚を本気で組む（ビームサーチ）

順位の高い配り方（上位10個）に加えて、**寄せ方（VoDa／DaVi／VoVi＝多く踏む2タイプ）ごとに最低2つ** は必ず本気で調べます。
ざっくりの点数だけで選ぶと、1つの寄せ方に偏って、ほかの寄せ方をちゃんと試さないまま終わることがあるからです。

6枚の組み方は **ビームサーチ** という方法を使います。

> 1枚目を決める → 2枚目を足す → 3枚目を足す … と進めるときに、
> **途中の段階で「良さそうな組み合わせ」を220個まで同時に残しながら進める** やり方です。
> 1個だけ残して進める（いちばん良い1枚を順に足す）よりも、相性の良い組み合わせを見つけやすくなります。

最後に残った上位の編成は、選抜の寄せ方（10種類）や授業の割り当てを変えた場合でも計算し直して、
「選抜をDaに寄せれば1位になる編成」のようなものも拾います。

### ④ 踏み方を詰め直す（山登り）

上位の候補（と、今の編成）について、編成を固定して踏み方だけを直します。

> **山登り** は「1か所だけ変えてみて、点数が上がったら採用する」を、上がらなくなるまで繰り返す方法です。
> 変える1か所は、レッスン1回のタイプ／サブ、授業1回のタイプ、選抜1つの配分、のどれかです。
> 出発点は、今の踏み方に引きずられないように、決まった9種類の形から始めます。

### ⑤ 仕上げ（1つずつでは越えられない壁を、合わせ技で越える）

山登りは「1か所ずつ」しか変えないので、**2〜3か所を同時に変えないと良くならない** 場合に止まってしまいます。
そこで仕上げでは、次のような合わせ技を順に試します。

- 選抜の点数配分を細かい比率（約60通り）で詰める
- レッスンの「日にち」を入れ替える（同じ回数でも、どの日に踏むかで上がり方が違う）
- 踏み方を変えたうえで、6枚を組み直す
- 「カード1枚の入れ替え ＋ レッスン1日の変更 ＋ 選抜の寄せ直し」を同時に試す
  （例: Daのカードを入れると Da があふれるが、レッスンを1日だけ別のタイプに逃がすと、あふれが消えて合計が上がる）

### ⑥ 最後の整え

- **前イベ・後イベの取得回数に制限があるとき**: どのカードのイベントを残すかを、実際に計算して決めます（制限がなければ、全部発動する設定にします）。
- **授業の寄せ**: 合計を下げない範囲で、授業を流行1位のタイプ→2位→3位の順に、決まった目安（2100／1400／1100）へ届くように割り当て直します。

### ⑦ 今より良ければ反映する

- 探索の結果が **今の評価値より低く、しかも今の編成が「条件設定」を全部守っている** ときは、何も変えません（押すたびに悪くなることはありません）。
- 今の編成が条件を守れていないとき（固定カードが入っていない、BANしたカードが入っている、など）は、評価値が下がっても条件を守る結果に置き換えます。

## 5. 「条件設定」はどう効くのか

| 条件 | 探索での扱い |
|---|---|
| 固定・BAN・レンタルNG（サポカ設定） | 固定は必ず入れる。BANは候補に入れない。レンタルNGはレンタル枠の候補にしない |
| SPレッスン率持ちの最低枚数 | 足りない編成には **とても大きな減点**（実質、選ばれない） |
| サポカ編成のタイプ割合 | 必ず守る条件。守れない編成は途中でも捨てる |
| ステの高さの順 | 必ず守る条件。順が崩れる候補は勝たせない |
| 最低ステータス | 届く候補を優先。全部は無理なら、審査基準の高いタイプから満たす |
| 最高ステータス | 超えた分の価値を小さく見積もる（わざわざ積みに行かない）。ほかの2タイプが上限なら、あふれても仕方ないので条件は満たした扱い |
| 前イベ・後イベの回数の制限 | 探索中はおおまかに見積もり、最後に「どのカードのイベントを残すか」を実際に計算して決める |
| 試験補助を強めにする | 試験に強いアイテム・ドリンク・SP率持ちのカードに、探索の中だけで加点する（画面の評価値は素のまま） |
| ステージ用アイテムを編成しない | 該当するカードを候補から外す（固定したカードは残る） |
| 選抜の点数配分（H.I.F） | 手で変えた配分を「そのまま固定」して、編成・レッスン・授業だけを探索できる。「全て1つのタイプに分配」にすると、選抜ごとに1タイプへ全部振る形だけを試す。**両方が効く場面では、手で変えた点数配分が優先**（評価値の下に「選抜は今の点数配分を優先」と出る） |

## 6. 3つのボタンの違い

| ボタン | 変えるもの | 変えないもの |
|---|---|---|
| **全自動**（青い大きなボタン） | サポカ6枚と踏み方の両方 | — |
| **編成だけ**（▾ の中） | サポカ6枚 | 踏み方（今のまま） |
| **踏み方だけ**（▾ の中／踏み方エディタのボタン） | 踏み方 | サポカ6枚（今のまま） |

どれを押しても、**前イベの取得・後イベの発動** は探索が決め直します（制限があればその通り、無ければ全部発動）。

## 7. 結果を見るときのヒント

- **「このカードが強いはずなのに入らない」**
  - そのタイプが上限であふれていないか（育成後のステータスのバーを見る）
  - プロデュースの発動回数が 0 になっていないか（点数の内訳で確認できます）
  - サポカ選択画面の **「合計 +◯／−◯」** が、そのカードに入れ替えたときの本当の増減です。点数が高くても、合計が下がるなら入りません。
- **「もう一度押したら結果が変わった」** → 探索は「今の編成と踏み方」も候補に入れて磨き直すので、続けて押すと、さらに少し良くなることがあります（条件を守れている限り、悪くなることはありません）。大きく変わったときは、所持状況・プロデュース・メモリー・条件設定のどれかが変わっています。
- **「もっと良い編成を自分で見つけた」** → あり得ます（近似なので）。その編成のまま「踏み方だけ」を押すと、その編成での最善の踏み方を出せます。
- **寄せ方（VoDa／DaVi／VoVi）**: 探索は3つの寄せ方をどれも本気で試してから、いちばん高いものを採用しています。別の寄せ方にしたいときは、「条件設定」の「ステの高さの順」や最低／最高ステータスで方向を指定できます。

## 8. 言葉のミニ辞典

| 言葉 | 意味 |
|---|---|
| 探索 | たくさんの候補の中から、点数の高いものを探すこと |
| 近似 | 「絶対にいちばん」ではないが、十分に良い答えを短い時間で出すこと |
| 候補（ショートリスト） | 最初に絞り込んだ、見込みのあるサポカの一覧 |
| ビームサーチ | 途中経過の「良さそうなもの」を何百個も同時に残しながら、1枚ずつ足して編成を組む方法 |
| 山登り | 1か所だけ変えて、良くなったら採用する、を繰り返して少しずつ良くする方法 |
| 合わせ技（結合手） | 2〜3か所を同時に変えてみること。1か所ずつでは越えられない壁を越えるため |
| 寄せ方（軸） | レッスンを多く踏む2タイプの組み合わせ（VoDa／DaVi／VoVi） |
| あふれ | ステータスが上限を超えて、評価値に入らなくなった分 |
